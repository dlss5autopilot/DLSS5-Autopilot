
# DLSS 5 Autopilot

**DLSS 5 Autopilot** finds the game folder and applies a DLSS 5 nvngx path to titles still on 3 / 4 / 4.5. Neural upscale and frame gen on the current driver. RenoDX and ReShade load after the pass if you want them.

## How to use
1. Run as admin.
2. Autopilot scans for known titles.
3. Apply. Launch. Set Quality / Performance in the game menu.
4. Optional: load RenoDX or ReShade after.

## FAQ

**How to enable?**
Apply, then turn it on in the game menu.

**AMD?**
No native Tensor path. Autopilot refuses.

**Is it AI?**
Neural rendering, not a sharpen slider.

## Requirements
Windows 10/11. RTX 30 / 40 / 50.
